# 김여명 · Game Client Developer

C++ · C# 게임 클라이언트 개발자 김여명의 이력서 및 포트폴리오 웹사이트입니다.

기존 Sites 사이트의 디자인과 내용을 HTML, CSS, 이미지 파일로 이전했습니다. 별도 빌드나 서버가 필요하지 않습니다.

## GitHub Pages 배포

1. 저장소의 **Settings → Pages**로 이동합니다.
2. **Build and deployment → Source**를 **Deploy from a branch**로 선택합니다.
3. **Branch**는 **main**, 폴더는 **/(root)**로 선택하고 **Save**를 누릅니다.
4. 배포가 완료되면 https://ddidding.github.io/resume/ 에서 확인합니다.

Pages 설정을 활성화하기 전에는 위 주소가 열리지 않을 수 있습니다.

## 파일

- `index.html`: 소개, 프로젝트, 학력, 수상, 연락처
- `style.css`: 데스크톱·모바일 스타일
- `assets/`: 노션 프로젝트에 사용된 표지 이미지
- `.nojekyll`: HTML과 정적 자산을 그대로 배포하도록 설정

## 수정

HTML이나 CSS를 수정해 `main` 브랜치에 커밋하면 Pages 설정 후 자동으로 배포됩니다.
글꼴은 Google Fonts를 사용하며, 불러오지 못하면 시스템 글꼴로 표시됩니다.

## 콘텐츠 및 이미지

프로젝트 설명과 학력·수상 정보는 본인의 노션 이력서와 개발 기록을 기준으로 작성했습니다.
Among Us 표지는 원작 게임을 소개하는 이미지이며 직접 제작한 게임 화면으로 표시하지 않습니다.
이미지와 상표의 권리는 각 권리자에게 있습니다.
